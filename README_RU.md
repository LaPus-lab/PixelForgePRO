# PixelForge PRO — Android-фоторедактор (первая сборка)

## Что уже реализовано
- Тёмный интерфейс на Jetpack Compose.
- Открытие изображения через системный выбор фото.
- Регуляторы яркости, контраста и насыщенности.
- Чёрно-белый фильтр.
- Поворот на 90 градусов и сброс настроек.
- Сохранение JPG в галерею в `Pictures/PixelForgePRO`.
- Без регистрации, без рекламы и без платных API в этой сборке.

## Важно про AI
В этой первой сборке AI Studio — обозначение будущего раздела, а не работающая ИИ-функция. Для удаления фона/объектов нужно отдельно подключить модель (например, локальную ML-модель или облачный API). Облачные API могут требовать ключ и плату; не встраивайте секретный ключ прямо в APK.

## Как получить APK
1. Установите Android Studio с официального сайта Android Developers.
2. Распакуйте ZIP в папку на компьютере.
3. В Android Studio выберите **Open** и укажите папку `PixelForgePRO`.
4. Дождитесь **Gradle Sync**. При запросе установите Android SDK 35 и JDK 17.
5. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. После успешной сборки нажмите ссылку **locate** в уведомлении Android Studio. Обычно APK лежит здесь:
   `app/build/outputs/apk/debug/app-debug.apk`
7. Передайте APK на телефон, откройте файл и разрешите установку из этого источника, если Android попросит.

## Как собрать через терминал
В корне проекта при установленном Android SDK и Gradle выполните:
`gradle assembleDebug`
APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Текущие ограничения
- Это исходный проект первой версии, а не уже собранный и протестированный APK.
- Перед выпуском нужно собрать и протестировать проект на реальном устройстве.
- Слои, маски, кисть, текст на изображении, обрезка и AI-обработка пока не реализованы.


## Сборка APK без компьютера (через GitHub Actions)
В проект добавлен workflow `.github/workflows/android-apk.yml`. После загрузки файлов проекта в GitHub-репозиторий открой вкладку **Actions**, выбери **Build PixelForge PRO APK**, нажми **Run workflow**. Когда сборка завершится успешно, открой запуск workflow, внизу раздел **Artifacts** и скачай `PixelForgePRO-debug-apk`. Это ZIP с APK внутри; распакуй его на телефоне и установи APK. GitHub может потребовать аккаунт; публичный репозиторий проще для бесплатной облачной сборки. Не загружай в репозиторий личные фотографии, пароли или ключи API.
